ozen is in early access, so installing it means pasting a few commands into Terminal. You only do this once, and
each step below says exactly what to copy. Plan on about 15 minutes, most of it waiting for downloads.

<Card title="You'll need" icon="list-format">
- A Mac with an Apple chip (M1 or newer) running macOS 15 Sequoia or later
- An invite to ozen on GitHub (ask whoever shared ozen with you)
- About 10 GB of free space, mostly for speech models
</Card>

## Setup

<Steps>

1. **Open Terminal.** Press <kbd>⌘</kbd> <kbd>Space</kbd>, type **Terminal**, press <kbd>Return</kbd>.
   To run a command below, click the copy button on it, paste it into Terminal with <kbd>⌘</kbd> <kbd>V</kbd>,
   and press <kbd>Return</kbd>.

2. **Install Apple's developer tools.** A window pops up; click **Install** and wait for it to finish.

   ```sh
   xcode-select --install
   ```

   If it says they're already installed, move on.

3. **Install Homebrew**, the standard way to add tools to a Mac. It asks for your Mac password (typing shows
   nothing; that's normal).

   ```sh
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

   When it finishes, it prints **Next steps** with two or three commands. Copy and run those too.

4. **Install the tools ozen is built with.**

   ```sh
   brew install rust uv ffmpeg gh
   ```

5. **Sign in to GitHub** so you can download ozen. Pick **GitHub.com**, then **Login with a web browser**, and
   follow along.

   ```sh
   gh auth login
   ```

6. **Download and build ozen.** The last command takes a few minutes.

   ```sh
   gh repo clone ozenhq/ozen ~/ozen
   gh repo clone tupe12334/voices-embedding-registry ~/ozen/voices
   cd ~/ozen && cargo run --release -- app
   ```

7. **Open ozen.** Press <kbd>⌘</kbd> <kbd>Space</kbd>, type **Ozen**, press <kbd>Return</kbd>. An ear appears in
   the menu bar at the top of your screen. ozen has no Dock icon; the ear is the app.

</Steps>

## Allow ozen to listen

The first time you press **Start**, macOS asks for two permissions. Allow both, then press **Start** again.

| macOS asks for | Why ozen needs it |
|---|---|
| **Screen & System Audio Recording** | To hear the audio of your meeting apps. ozen never records video of your screen. |
| **Microphone** | To hear people in the room, including you. |

If you missed the pop-up, open **System Settings › Privacy & Security**, find each of those, and turn on **Ozen**.

Later, if you set up [places](/guides/recording/#places), macOS also asks for **Location Services**.

<Aside title="The first meeting is slower">
ozen downloads its speech models (about 7 GB) the first time it transcribes. Until that finishes, lines appear
late and the panel may say it's catching up. After that, everything runs offline.
</Aside>

## Updating

When there's a new version, open Terminal and run:

```sh
cd ~/ozen && git pull && cargo run --release -- app
```

Updating never interrupts a recording in progress, and your permissions stay.

## Using ozen on a second Mac

Repeat the setup on the other Mac. People you name on one Mac are recognized on the other within a few minutes.
See [Using several Macs](/guides/multi-mac/).
